# BoBudget — сайт

Сайт-визитка приложения BoBudget (учёт расходов голосом, текстом и по фото чека).
Языки: English (`/`), русский (`/ru/`), українська (`/uk/`).

https://bogdanhere1.github.io/bobudget/

Статика без сборщиков: страницы генерирует `build.py` из одного шаблона и словаря текстов.

```bash
python build.py
```
